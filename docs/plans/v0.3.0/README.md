# v0.3.0 — カレンダーグリッド

## 目的

月間・週間・年間ビュー用の日付グリッドを生成する。

## 含む機能

- [calendar-grid.md](../v1.0.0/calendar-grid.md)
- 必要週のみ返す（4〜6）。週数固定オプションは持たない
- 週開始などの設定検証

## 受け入れ条件

- うるう年・月跨ぎ・週開始変更の単体テストが緑
- 戻り値にピクセル・CSS クラスを含めない

## 依存関係

- **前提:** v0.2.0
- **利用側:** `@b4m/final-calendar` の月表示（v0.2.0）が本版のグリッドを消費する想定。5/6 週の見た目揃えは表示側
