## U-03 週番号の既定

| 案 | 内容 |
|----|------|
| A | ISO 8601（月曜始まり・第 1 週は 4 日以上含む）を既定。設定で上書き |
| B | `weekStartsOn` のみで簡易週番号（年の第 1 日を含む週を 1） |
| C | 既定なし。呼び出し必須 |

**推奨: A。** 国際的な既定として説明しやすい。US 週などは設定で。

## U-04 月間グリッドの週数

| 案 | 内容 |
|----|------|
| A | 必要週のみ返す（4〜6）。固定しない（PO） |
| B | 常に 6 週 |
| C | 呼び出しで `minWeeks` / `maxWeeks` を指定 |

**推奨: A。** final-calendar の「5 週/6 週指定」は表示側で切り詰めまたは余白。必要なら v0.3 以降で C を MINOR 追加。

## U-05 終日予定の正規表現

| 案 | 内容 |
|----|------|
| A | `LocalDate` の半開区間を正規とする（Instant は派生） |
| B | Instant のみ。終日は TZ の 0:00〜翌 0:00 |
| C | 両方を必須フィールドにする |

**推奨: A。** PO の「TZ 変換で日付がずれない」を優先。B は表示ずれリスクが高い。

## U-06 DST の存在しない／重複時刻

| 案 | 内容 |
|----|------|
| A | 存在しない→直後の有効時刻、重複→オフセットが早い方（または明示オプション） |
| B | 常にエラー |
| C | ライブラリごとに異なる挙動を許容 |

**推奨: A を既定とし、厳密モード（B）をオプション。** 決定的で、カレンダー UI が止まりにくい。

## U-07 レーン割り当て順

| 案 | 内容 |
|----|------|
| A | `start` 昇順 → 期間の長い順（`end` 降順）→ `id` 昇順 |

**推奨: A。** 決定的で、長い予定が左（または上）レーンに寄りやすい。C は v1 後でも可。

## U-08 休日プロバイダ
