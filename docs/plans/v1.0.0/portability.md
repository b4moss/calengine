# 移植性（TypeScript ↔ Go）

状態: 仕様詳細（未実装）。PO 初期ドキュメント §13・§15 の意図を維持。

## v1 で揃える共有対象

- 日付演算の規則
- 週番号の計算規則
- 月間・週間グリッドの生成規則
- 日付範囲の境界規則
- 予定の重複判定
- 複数日分割・レーン割り当て規則
- エラー条件

JSON で表現可能な入出力を優先し、共通テストケースを用意する。

## 目標

同一入力に対し TypeScript と Go で同じ論理的出力を得られること。

タイムゾーン DB のバージョン差など環境依存の差は明示的に扱う（テストで TZDB 版を記録する等）。

## Go 移植本体

リポジトリ追加や Go モジュール公開は After-v1.0.0（[unscheduled/go-port.md](../unscheduled/go-port.md)）。v1 ではフィクスチャと仕様の共有可能な形まで。

## 非機能

- Node とブラウザ双方で利用可能な構成を目指す
- 実行時依存は最小限（TZ は U-09 決定: `Intl`＋必要なら小さな補助）
- 型定義を公開。Tree shaking に配慮
- 主要な演算は決定的。不要なオブジェクト生成は避けるが可読性を優先
